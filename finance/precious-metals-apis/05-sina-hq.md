# 05 · 新浪财经行情接口 hq.sinajs.cn

## 渠道概况

| 项目 | 内容 |
|---|---|
| 提供方 | 新浪财经 |
| 主机 | hq.sinajs.cn |
| 官方程度 | 行情聚合（非交易所官方） |
| 鉴权 | 无 Key，但必须带 Referer 请求头 |
| 实时性 | 免费接口延迟约 10–15 分钟 |
| 编码 | GBK |
| 特色 | 国内少数免费提供人民币贵金属行情的接口（上金所 T+D、沪金/沪银期货主力） |

## 请求

GET https://hq.sinajs.cn/list={代码1},{代码2},...

| 元素 | 必填 | 说明 |
|---|---|---|
| list | 是 | 行情代码，逗号分隔批量 |
| 请求头 Referer | 是 | 必须为 https://finance.sina.com.cn（社区长期共识，不带会被拒或空返回） |
| 其他头 | 否 | 无要求 |

### 本会话实测记录

- 会话抓取工具不支持自定义请求头，新浪响应（无 Referer 的请求）返回体存在但解码失败（unsupported content type "unknown"，即 GBK 文本无标准 content-type）；
- 沙箱内 pwsh/curl 无外网，无法本地复核；接口连通性已确认，字段与 Referer 行为依据社区文档，请本地按下方命令验证。

## 代码枚举（贵金属/汇率相关）

| 代码 | 品种 | 单位 | 来源 |
|---|---|---|---|
| gds_AUTD | 上海黄金交易所 黄金延期 Au(T+D) | 元/克 | 社区文档 |
| gds_AGTD | 上海黄金交易所 白银延期 Ag(T+D) | 元/千克 | 社区文档 |
| hf_XAU | 伦敦金（现货黄金） | 文档标"元/千克"，存疑 | 社区文档 |
| hf_XAG | 伦敦银（现货白银） | 同上 | 社区文档 |
| nf_AU0 | 沪金期货主力 | 元/克 | 社区文档 |
| nf_AG0 | 沪银期货主力 | 元/千克 | 社区文档 |

## 代码示例（含 Referer 与 GBK）

### Python

```python
import requests

url = "https://hq.sinajs.cn/list=gds_AUTD,gds_AGTD,hf_XAU,USDCNY"
headers = {"Referer": "https://finance.sina.com.cn"}
text = requests.get(url, headers=headers, timeout=10).content.decode("gbk")
for line in text.strip().splitlines():
    code = line.split("=")[0].replace("var hq_str_", "")
    fields = line.split('"')[1].split(",")
    print(code, fields[0], fields[-1])
```

### PowerShell（本地验证命令）

```powershell
$r = Invoke-WebRequest -Headers @{Referer="https://finance.sina.com.cn"} -Uri "https://hq.sinajs.cn/list=gds_AUTD,hf_XAU,USDCNY"
[System.Text.Encoding]::GetEncoding("GB2312").GetString($r.RawContentStream.ToArray())
```

## 注意事项

1. 必须带 Referer：这是与腾讯接口最大的不同。
2. GBK 编码。
3. 免费接口延迟 10–15 分钟，非实时。
4. 新浪无官方字段文档，字段顺序"可能变化"（社区文档原话）；接入后自建校验。
5. hf_XAU 单位文档标注存疑（疑为美元/盎司），务必交叉核对。
   > **2026-09-25 补充实测**：同一时刻新浪 `hf_XAU` 的量级与腾讯 `hf_XAU`（4273.02）、gold-api.com（4274.30）、Swissquote（4271.90）完全一致，可确认该字段为**美元/盎司**，社区文档标注的"元/千克"有误。
6. 人民币 T+D 与沪金/沪银：非交易时段（夜市休市）返回的是最近收盘快照。
