# 04 · 东方财富 push2 行情接口

## 渠道概况

| 项目 | 内容 |
|---|---|
| 提供方 | 东方财富（行情数据经行情商授权） |
| 主机 | `push2.eastmoney.com` |
| 官方程度 | 行情聚合（非交易所官方） |
| 鉴权 | 无 |
| 实时性 | **延迟行情**（与腾讯实测同品种低约 5 美元/盎司，即延迟所致） |
| 数据形态 | 标准 JSON，编码 UTF-8 |

## 请求

```http
GET https://push2.eastmoney.com/api/qt/stock/get?secid={市场.代码}&fields={字段串}
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `secid` | ✅ | 格式 `市场ID.代码`，如 `101.GC00Y` |
| `fields` | ✅ | 逗号分隔字段码，如 `f43,f57,f58,f169,f170` |
| `cb` | ❌ | JSONP 回调名（本会话以 `cb=` 空值实测仍返回裸 JSON，JSONP 行为未深究） |

- 请求头无要求。
- 另有 `ut`、`fltt`、`invt`、`wbp2u` 等参数常见于社区抓包，本会话未使用也未被要求。

## secid 实测矩阵（2026-09-05）

| secid | 品种 | 结果 |
|---|---|---|
| `101.GC00Y` | COMEX 黄金主力 | ✅ 有效，`rc=0` |
| `101.SI00Y` | COMEX 白银主力 | ✅ 有效，`rc=0` |
| `101.PL00Y` | 铂金（猜测） | ❌ `data:null`（secid 无效） |
| `101.PA00Y` | 钯金（猜测） | ❌ `data:null` |
| `113.AU00` | 沪金主力（猜测） | ❌ `data:null` |
| `113.au0` | 沪金主力（另一种写法） | ❌ `data:null` |
| `100.102030` | 伦敦金现（社区旧文档） | ❌ `data:null`（已失效或改号） |
| `100.102031` / `100.103030` / `103.102030` | 伦敦金现（其他猜测） | ❌ 网络错误或 `data:null` |

> `101.` 为外盘市场 ID。**铂钯与上金所 secid 未探明**，需在东方财富网页版打开对应行情页、从浏览器 DevTools 抓取真实 secid。

## 响应格式

### 成功（secid 有效）

```json
{"rc":0,"rt":4,"svr":180606388,"lt":1,"full":1,"dlmkts":"","dsc":"0","data":{"f43":44772,"f44":45378,"f45":44120,"f46":45220,"f57":"GC00Y","f58":"COMEX黄金","f60":45399,"f169":-627,"f170":-138,"f171":277}}
```

### 无效 secid

```json
{"rc":100,"rt":1,"svr":180606319,"lt":1,"full":1,"dlmkts":"","dsc":"0","data":null}
```

- `rc=0` 成功、`rc=100` 无效；`svr` 服务器实例、`rt`/`lt`/`full` 内部状态，可忽略。

### 常用字段码

| 字段码 | 含义 | 备注 |
|---|---|---|
| `f43` | 最新价 | **有缩放，因品种而异**（见下） |
| `f44` | 最高价 | 缩放同 f43 |
| `f45` | 最低价 | 缩放同 f43 |
| `f46` | 今开 | 缩放同 f43 |
| `f57` | 代码 | 如 `GC00Y` |
| `f58` | 中文名 | 如 `COMEX黄金` |
| `f60` | 昨收 | 缩放同 f43 |
| `f169` | 涨跌额 | 缩放同 f43 |
| `f170` | 涨跌幅 | ×100（如 -138 = -1.38%） |
| `f171` | 成交量 | 手 |
| `f47` | 成交量（另一口径） | 社区常用，未实测 |

### 缩放规则（实测推导，**必须按品种校准**）

| 品种 | 缩放 | 实测推导 |
|---|---|---|
| COMEX 黄金 `GC00Y` | **×10** | f43=44772→4477.2；f60=45399→4539.9；f169=-627→-62.7；验证 4477.2-4539.9=-62.7 ✅ |
| COMEX 白银 `SI00Y` | **×1000** | f43=66820→66.82；f60=67704→67.704；f169=-884→-0.884；验证 66.82-67.704=-0.884 ✅ |

同一 `f43` 在不同品种上缩放不同（黄金 ×10、白银 ×1000），**接入新品种必须先做"最新价−昨收=涨跌额"三数交叉校验**。

### 实测原始数据（2026-09-05 10:20 北京时间）

```json
{"f43":44772,"f44":45378,"f45":44120,"f46":45220,"f57":"GC00Y","f58":"COMEX黄金","f60":45399,"f169":-627,"f170":-138,"f171":277}
{"f43":66820,"f44":67810,"f45":65335,"f46":67630,"f57":"SI00Y","f58":"COMEX白银","f60":67704,"f169":-884,"f170":-131,"f171":366}
```

换算后：COMEX 黄金 4477.2 美元/盎司（-1.38%）、COMEX 白银 66.82 美元/盎司（-1.31%）。

## 代码示例

```python
import requests

def em_quote(secid, scale):
    url = f"https://push2.eastmoney.com/api/qt/stock/get?secid={secid}&fields=f43,f44,f45,f46,f57,f58,f60,f169,f170,f171"
    j = requests.get(url, timeout=10).json()
    if j["rc"] != 0 or not j["data"]:
        return None   # secid 无效
    d = j["data"]
    return {
        "名称": d["f58"], "代码": d["f57"],
        "最新价": d["f43"] / scale,
        "昨收": d["f60"] / scale,
        "涨跌额": d["f169"] / scale,
        "涨跌幅%": d["f170"] / 100,
    }

print(em_quote("101.GC00Y", 10))
print(em_quote("101.SI00Y", 1000))
```

## 注意事项

1. **f43 缩放是最大坑**：同一字段不同品种缩放不同，且无官方文档，只能交叉校验。
2. 延迟行情：与腾讯同品种同时刻对比低约 5 美元/盎司。
3. `push2` 偶发网络错误（本会话多次 `fetch failed`），需要重试机制。
4. secid 需从东方财富官网页面抓包获得；社区流传的伦敦金现 secid `100.102030` 实测已失效。
5. 免费接口无 SLA、勿商用分发。
