## 统一换算公式与双汇率口径

```
元/克 = 美元/盎司 × USDCNY ÷ 31.1034768
```

1 金衡盎司（oz t）= 31.1034768 克。金、银、铂、钯的盎司报价均按金衡盎司计。

| 汇率口径 | 来源 | 实测值（2026-09-24） | 换算系数 |
|---|---|---|---|
| **CFETS 官方中间价**（境内口径） | [12 号文档 §12.1](12-official-cny-and-fx.md) | 6.7489 | **0.216982** |
| ECB / 市场汇率（跨境口径） | [12 号文档 §12.3](12-official-cny-and-fx.md)、[07 号](07-open-er-api.md) | 6.7126 | **0.215815** |

⚠️ **两个口径相差约 0.54%，折算到 4274 美元/盎司上是约 5 元/克**（927.45 vs 922.46）——选错汇率口径带来的误差，远大于各行情源之间的差异（四源极差仅 0.06%）。

判别依据（本次实测）：

1. 上金所 2026-09-24 收盘 **926.01 元/克**，只落在中国价口径区间 **923.38–927.45** 内；市场口径区间仅 918.41–922.46，明显偏低；
2. goldprice.dev 自报的 **921.97 元/克**与市场口径的 921.94 几乎完全重合。

**结论：境内行情对比 / 基准价 / 结算 → 用 CFETS 中间价；跨境组合估值 / 境外 API 对账 → 用市场汇率。**

换算示例：

| 场景 | 计算 | 结果 |
|---|---|---|
| 伦敦金 4274.30 USD/oz → 中间价 | 4274.30 × 6.7489 ÷ 31.1034768 | **927.45 元/克** |
| 伦敦金 4274.30 USD/oz → 市场汇率 | 4274.30 × 6.7126 ÷ 31.1034768 | **922.46 元/克** |
| 铂 1750.18 USD/oz（买卖中值） → 中间价 | 1750.18 × 0.216982 | **379.76 元/克** |
| 钯 1259.18 USD/oz（买卖中值） → 中间价 | 1259.18 × 0.216982 | **273.22 元/克** |
| 银 63.87 USD/oz → 中间价 | 63.87 × 0.216982 | **13.86 元/克** |

```python
def cny_per_gram(usd_per_oz, usdcny, ozt=31.1034768):
    return usd_per_oz * usdcny / ozt

cny_per_gram(4274.30, 6.7489)   # 927.45  ← CFETS 中间价口径
cny_per_gram(4274.30, 6.7126)   # 922.46  ← 市场汇率口径
```

## 本环境实测限制（重要）

- 沙箱内 pwsh/curl **无外网**，所有网络验证均通过会话内置 fetch 工具完成；
- 该工具对单个响应体有 **约 100,000 字符截断上限**：LBMA 全量历史 JSON（>100KB）、上金所 `Ag(T+D)` 日线、上期所全品种日线均无法读到末尾，相关"最新值"以可读区段为准并已在各文件中逐处标注；
- 该工具**不支持自定义请求头**：新浪（必带 Referer）只能验证连通性、无法解码 GBK 响应；腾讯（GBK）与黄金 ETF 行情可正常返回；
- GitHub / raw.githubusercontent 在本环境被屏蔽，metals.dev 的 OpenAPI（09）与 goldprice.dev 的技能说明（11）经 jsdelivr 镜像获取；
- Yahoo Finance 对中国大陆返回 403；Binance / CoinGecko / Kraken 等加密货币域名在本环境不可达、OKX 被判定为非公网 IP——**属环境限制，不代表接口失效**；
- 上金所 `/graph/` 下未探明的路径**不返回 404，而是回落首页 HTML（HTTP 200）**，程序必须校验响应体（见 [10 号文档](10-sge-official.md)）；
- 失败与受限清单汇总见 [12 号文档 §12.7](12-official-cny-and-fx.md)。
