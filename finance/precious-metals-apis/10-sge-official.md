# 10 · 上海黄金交易所（SGE）官方 JSON 接口

## 渠道概况

| 项目 | 内容 |
|---|---|
| 机构 | 上海黄金交易所（Shanghai Gold Exchange，SGE）—— 中国唯一的黄金现货交易所 |
| 主机 | `www.sge.com.cn` |
| 官方程度 | ★★★★★ 交易所官方 |
| 鉴权 | 无（公开页面自用端点） |
| 实时性 | 分时为分钟级准实时（响应内 `delaystr` 标明数据时点）；日线为收盘后定稿 |
| 计价货币 | **人民币原生**：Au 系列 元/克，`Ag(T+D)` 元/千克 |
| 交易时段 | 夜市 20:00–次日 02:30 + 日盘 09:00–11:30 / 13:30–15:30（实测 `times` 数组覆盖全时段） |
| 官方文档 | ❌ 无。端点为官网图表页面自用接口，属"约定俗成"的公开端点 |

> **本篇修正了 02 号文档的结论**。02 号曾写"上海黄金交易所本身不提供免费 API，人民币价只能经 WGC 的 `sge_am_cny/sge_pm_cny` 取"。实测 SGE 官网有两个直出的 JSON 端点：无需 Key、无需请求头，且比 WGC 多出**分钟级分时**与**2016 年起的逐日 OHLC**。

## 端点

### 端点一：当日分时 `/graph/quotations`

```http
GET https://www.sge.com.cn/graph/quotations
```

| 元素 | 必填 | 说明 |
|---|---|---|
| 参数 | — | 实测无参数即可；是否支持 `instid` 等参数切换合约**未探明** |
| 请求头 | — | 无要求 |

实测响应（2026-09-25 会话，数据日 2026-09-24）：

```json
{
  "times": ["20:00", "20:01", "20:02", "…", "15:30"],
  "min": 924,
  "data": ["934.0", "932.0", "932.0", "…", "926.5"],
  "max": 935,
  "heyue": "Au99.99",
  "delaystr": "2026年09月24日 15:45:00"
}
```

| 字段 | 类型 | 含义 |
|---|---|---|
| `times` | string[] | 分钟时间轴，覆盖夜市 20:00→次日 02:30 与日盘 09:00→15:30 |
| `data` | **string[]** | 与 `times` 下标一一对应的分钟价（**字符串**，需自行转数值） |
| `min` / `max` | number | 当日区间，**整数**（实测 924 / 935，与日线的 924.1 / 935.78 有截断差） |
| `heyue` | string | 合约名，默认实测为 `Au99.99` |
| `delaystr` | string | 数据时点（实测 `2026年09月24日 15:45:00`），非交易时段返回最近交易日快照 |

### 端点二：历史日线 `/graph/Dailyhq`

```http
GET https://www.sge.com.cn/graph/Dailyhq?instid=Au99.99
```

| 参数 | 必填 | 说明 |
|---|---|---|
| `instid` | 实测必填 | 合约名；含括号的合约需 URL 编码，如 `Ag(T+D)` → `Ag%28T%2BD%29` |

响应为**单行 JSON**，`time` 数组内每个元素是一条日线：

```json
{"time": [["2016-12-19", 262.45, 262.76, 262.02, 263.5], "…", ["2026-09-24", 932.0, 926.01, 924.1, 935.78]]}
```

> ⚠️ **字段序是最大的坑**：`[日期, 开盘价, 收盘价, 最低价, 最高价]` —— **末两列是"低、高"**，与官网"每日行情"表头的列序（开盘价 / 收盘价 / **最高价 / 最低价**）**恰好相反**。照抄表头会把最高最低读反。

字段序的验证依据（两条独立证据）：

1. **夹逼校验**：末条 `["2026-09-24", 932.0, 926.01, 924.1, 935.78]` → `924.1 ≤ 926.01 ≤ 935.78` 且 `924.1 ≤ 932.0 ≤ 935.78` 成立；若按表头把第 3 列当"最高价"，则出现 最高价 924.1 < 最低价 935.78 的矛盾。
2. **跨端点一致**：同一天 `/graph/quotations` 的 `min:924 / max:935` 与日线的低 924.1 / 高 935.78 吻合。

接入后建议常驻自校验：

```python
d, o, c, lo, hi = rows[-1]
assert lo <= min(o, c) and hi >= max(o, c), "SGE 字段序疑似变更，请重新核对"
```

### 合约枚举

| instid | 品种 | 单位 | 实测状态 |
|---|---|---|---|
| `Au99.99` | 黄金 99.99 现货 | 元/克 | ✅ 实测，首条 `["2016-12-19",262.45,…]` |
| `Ag(T+D)`（需编码为 `Ag%28T%2BD%29`） | 白银延期 | 元/千克 | ✅ 实测，首条 `["2016-12-16",3984.0,…]` |
| `Au(T+D)` / `mAu(T+D)` / `Au99.95` / `Au100g` / `Pt99.95` / `iAu99.99` / `Ag99.99` / `Au(T+N1)` / `Au(T+N2)` / `Au99.5` / `iAu100g` / `iAu99.5` / `PGC30g` / `NYAuTN06` / `NYAuTN12` | — | — | ⚠️ 仅从官网 `/sjzx/mrhq` 合约下拉框枚举得到，**未逐一实测** |

### ⚠️ 未探明路径的行为（重要）

`/graph/` 下**不存在的路径不返回 404，而是回落返回交易所首页 HTML（HTTP 200）**。实测 `/graph/DaylyQuotation`、`/graph/shanghaiAuAuto`、`/graph/goldEtf` 三个猜测路径全部返回首页 HTML。

因此程序里**必须校验响应体**（`Content-Type` 或首字符是否为 `{`），只看状态码会把首页 HTML 当成行情数据解析。

## 实测快照（2026-09-25 会话）

`/graph/Dailyhq?instid=Au99.99` 末尾 3 条：

```text
["2026-09-22", 941.5, 931.98, 930.0, 951.5]
["2026-09-23", 932.0, 934.0,  932.0, 940.0]
["2026-09-24", 932.0, 926.01, 924.1, 935.78]
```

`/graph/quotations`：`heyue=Au99.99`，`delaystr=2026年09月24日 15:45:00`，`min=924`，`max=935`，`times` 从 `20:00` 起、`15:30` 止。

**官方上海金基准价（HTML 页面抓取，非 JSON 接口）**：官网首页 `/` 内嵌「行情日期 2026-09-24：上海金早盘价 **928.27** 元/克、午盘价 **924.45** 元/克」。这与 02 号文档 WGC 的 `sge_am_cny` / `sge_pm_cny` 同源——需要**结构化 JSON** 时仍走 WGC（02 号文档）更省事；需要**当日最快**时可解析首页 HTML。

`Ag(T+D)` 响应体超过本会话 fetch 工具的 100,000 字符上限，只读到 2026-06 区段，**末条未读到**；如需最新白银 T+D 日线请在本地直接请求。

## 代码示例

### Python

```python
import requests

UA = {"User-Agent": "Mozilla/5.0"}   # 建议携带；实测裸请求亦可

# 1) 当日分时
q = requests.get("https://www.sge.com.cn/graph/quotations", headers=UA, timeout=10).json()
assert "data" in q, "未拿到 JSON，可能已改版或回落到首页 HTML"
print(q["heyue"], "最新", q["data"][-1], "区间", q["min"], "-", q["max"], "数据时点", q["delaystr"])

# 2) 历史日线（Au99.99 / Ag(T+D) 需 URL 编码）
h = requests.get("https://www.sge.com.cn/graph/Dailyhq",
                 params={"instid": "Au99.99"}, headers=UA, timeout=20)
h.raise_for_status()
rows = h.json()["time"]
d, o, c, lo, hi = rows[-1]
assert lo <= min(o, c) and hi >= max(o, c), "字段序疑似变更"
print(d, "开", o, "收", c, "低", lo, "高", hi)   # 2026-09-24 开 932.0 收 926.01 低 924.1 高 935.78
```

### PowerShell

```powershell
# 当日分时最新价
$q = Invoke-RestMethod 'https://www.sge.com.cn/graph/quotations'
"$($q.heyue) 最新 $($q.data[-1])  区间 $($q.min)-$($q.max)  $($q.delaystr)"

# 历史日线最后一条（返回数组：日期, 开, 收, 低, 高）
$r = Invoke-RestMethod 'https://www.sge.com.cn/graph/Dailyhq?instid=Au99.99'
$r.time[-1] -join '  '
```

## 注意事项

1. **这是境内最权威的人民币金价来源**（交易所官方、原生元/克），优先级应高于任何第三方聚合接口；但**无官方 API 文档与 SLA**，属页面自用接口，改版即可能失效——务必保留降级路径（02 号 WGC / 08·09 号商业 API）。
2. 分时不是 tick 级：`quotations` 为分钟序列，且 `delaystr` 明确标注数据时点；非交易时段（含周末、节假日）返回**最近交易日快照**，不要误判为"当前价"。
3. 日线起点为 2016-12（Au99.99 自 2016-12-19，`Ag(T+D)` 自 2016-12-16）；更早历史请用 LBMA（01 号）/ WGC（02 号）/ 商业 API（08·09 号）。
4. `min/max` 为整数、日线为两位小数，两者存在 ±1 元的截断差，做一致性比对时请容忍。
5. 商用与再分发请先确认上金所数据授权条款；本文档仅记录公开页面所使用的接口。
6. 全站 HTTPS，但 CORS 未实测；浏览器前端直连大概率受限，建议经后端代理。
