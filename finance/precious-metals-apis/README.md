## 选型建议

- **要权威**：LBMA JSON / WGC fsapi / FRED（官方、免费、可追溯）
- **要快**：腾讯（准实时、无鉴权、无请求头）
- **要人民币**：WGC 的 `sge_am_cny/sge_pm_cny`（官方上海金）或新浪 `gds_AUTD`（T+D）
- **要省事**：东方财富（JSON 规范、免鉴权）
- **要商用/多币种/规范化文档**：GoldAPI.io、Metals.dev（注册 Key，有免费层）
- **换汇率**：open.er-api.com

## 统一换算公式

```
元/克 = 美元/盎司 × USDCNY ÷ 31.1034768
```

1 金衡盎司（oz t）= 31.1034768 克。金、银、铂、钯的盎司报价均按金衡盎司计。

## 本环境实测限制（重要）

- 沙箱内 pwsh/curl **无外网**（连百度都失败），所有网络验证均通过会话内置 fetch 工具完成；
- 该工具对单个响应体有 **约 100,000 字符截断上限**，因此 LBMA 全量历史 JSON（>100KB）无法读到末尾，最新定盘值改经 WGC 官方 API 同源获取；
- 该工具不支持自定义请求头，新浪（必带 Referer）只能验证连通性、无法解码 GBK 响应；
- GitHub/raw.githubusercontent 在本环境被屏蔽，metals.dev 的 OpenAPI 经 jsdelivr 镜像获取。
