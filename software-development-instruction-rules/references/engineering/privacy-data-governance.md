# 隐私与数据治理

在系统处理个人信息、敏感数据、生产测试数据、跨境或第三方共享，或变更数据保留与删除方式时读取。先识别真实法律、合同和组织要求；本技能不臆造适用法域或合法处理依据。

- [PRV-01] 建立与本次范围相称的数据清单和数据流，标明数据类别、来源、目的、主体、所有者、存储位置、接收方、保留期限及删除路径。
- [PRV-02] 对收集、使用、共享和保留说明必要目的与最小化依据；超出已确认目的的新用途须经过适当评估和决定。
- [PRV-03] 识别适用的通知、同意、访问、更正、导出、限制和删除要求，并将其落实为需求、设计、操作和验证证据。
- [PRV-04] 高影响处理、敏感数据、系统性监测、自动决策或风险显著变化时，执行适用的隐私影响评估或等效审查，记录风险、缓解措施和有权决定者。
- [PRV-05] 测试和分析优先使用合成、脱敏或最小必要数据；使用生产数据须有明确授权、访问控制、隔离、保留和销毁安排。
- [PRV-06] 第三方共享、跨区域传输和外部处理须识别接收方、目的、数据范围、安全措施、合同义务及退出或删除证明。
- [PRV-07] 日志、追踪、指标、错误报告、备份和模型训练数据不得因“可观测性”或调试便利超范围保留敏感信息。
- [PRV-08] 保留期届满、用户请求或系统退役时，按适用义务执行删除、匿名化或归档，并处理副本、缓存、备份和下游接收方；不能删除时说明依据和访问限制。

所需证据可包括数据清单与数据流、处理目的和保留规则、隐私影响评估、测试数据授权、第三方协议、访问复核及删除或匿名化验证。关键数据用途、主体权利或保留义务未明确时，不得将涉及该处理的需求、设计或退役门禁判为通过。
