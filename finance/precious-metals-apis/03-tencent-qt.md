# 03 · 腾讯财经行情接口 qt.gtimg.cn

## 渠道概况

| 项目 | 内容 |
|---|---|
| 提供方 | 腾讯财经（行情数据由行情商供应） |
| 主机 | `qt.gtimg.cn` |
| 官方程度 | 行情聚合（非交易所官方） |
| 鉴权 | 无 |
| 实时性 | 准实时（实测值与 COMEX 收盘价一致；外盘品种在亚洲时段为最近收盘/最新现价） |
| 编码 | **GBK**（程序内必须转码） |
| 协议 | HTTP 与 HTTPS 均可用 |

## 请求

```http
GET https://qt.gtimg.cn/q={代码1},{代码2},...&r={随机数}
```

| 参数 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `q` | ✅ | string | 行情代码，**逗号分隔可批量**（一请求多品种） |
| `r` | ❌ | number | 任意随机数/时间戳，防 CDN 缓存 |

- **请求头**：无要求（无需 Referer、UA 均可）。
- **失败形态**：无效代码不报错，返回 `v_pv_none_match="1";`。

## 响应格式

每个代码返回一行，格式：

```text
v_{代码}="字段1,字段2,...,字段14";
```

多代码按 `q` 参数顺序逐行返回，行间以换行分隔。

### 14 字段详解（实测推导 + 交叉验证）

| # | 字段 | 含义 | 验证依据 |
|---|---|---|---|
| 1 | 最新价 | 现价/最近成交价 | — |
| 2 | 涨跌幅% | 相对昨收的百分比 | 见下公式验证 ✅ |
| 3 | 买价（bid） | 当前买一价 | 现货品种与最新价几乎一致 |
| 4 | 卖价（ask） | 当前卖一价 | 现货品种比买价高数个最小变动 |
| 5 | 最高价 | 当日最高 | — |
| 6 | 最低价 | 当日最低 | — |
| 7 | 时间 | `HH:MM:SS`，交易时间戳（社区一般解读为 UTC，未经官方确认） | — |
| 8 | 昨收 | 上一交易日收盘 | **公式验证** ✅ |
| 9 | 今开 | 当日开盘 | — |
| 10 | 成交量 | 外盘现货常为 0 | — |
| 11 | 持仓量 | 期货品种有值 | GC=1, SI=3（口径存疑） |
| 12 | 买量 | 外盘常为 0 或小整数 | GC=2, SI=2 |
| 13 | 日期 | `YYYY-MM-DD` 交易日期 | — |
| 14 | 名称 | 中文品种名 | — |

## 代码示例（含 GBK 转码）

### Python

```python
import requests

url = "https://qt.gtimg.cn/q=hf_XAU,hf_XAG,hf_GC,hf_SI"
text = requests.get(url, timeout=10).content.decode("gbk")   # 关键：GBK 解码
for line in text.strip().splitlines():
    code = line.split("=")[0].replace("v_", "")
    fields = line.split('"')[1].split(",")
    print(code, "最新价:", fields[0], "涨跌幅%:", fields[1], "昨收:", fields[7], "日期:", fields[12])
```

### PowerShell

```powershell
$wc = New-Object System.Net.WebClient
$wc.Encoding = [System.Text.Encoding]::GetEncoding("GB2312")
$t = $wc.DownloadString("https://qt.gtimg.cn/q=hf_XAU")
$t   # v_hf_XAU="4430.96,..."
```

## 注意事项

1. **GBK 编码**是最大坑：UTF-8 直接读会出现名称乱码。
2. 字段顺序基于实测推导，腾讯无公开文档，可能变动；接入后建议用"涨跌幅↔昨收"公式自校验。
3. 外盘（`hf_`）在亚洲白天显示的是**最近收盘/最新现价**（时间戳为美盘收盘时点），非连续交易中的实时 tick；国内期货类代码（如 `hf_` 外的国内品种）才有盘中实时。
4. 铂、钯代码未探明（`hf_PA`/`hf_PL` 无效）；需要铂钯实时价可用 LBMA 官方文件（01）或 GoldAPI.io/metals.dev（08/09）。
5. 免费接口无 SLA、勿用于商业分发。
